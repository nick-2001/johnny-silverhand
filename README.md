## Install

Run from the repository root on macOS:

```sh
mkdir -p "$HOME/.codex/pets/johnny-silverhand"
cp johnny-silverhand/{pet.json,spritesheet.png} "$HOME/.codex/pets/johnny-silverhand/"
```

Refresh the Codex pet picker and select **强尼·银手** (Johnny Silverhand).

## Preview

Open [preview.html](preview.html) locally to explore the animations. Source artwork, prompts, and experiments are in [assets/](assets/), [docs/](docs/), and [archive/](archive/). v2 gaze animations are unfinished.
